# PRO FIT

A mobile-first React + TypeScript fitness tracker. Workout and profile data stay on the device in `localStorage`.

## Run locally

Install Node.js 20+ and run:

```sh
npm install
npm run dev -- --host 0.0.0.0
```

Open the shown address on the computer, or its local-network address on an iPhone connected to the same Wi-Fi. For a shareable, installable version, deploy the repository to a static host such as Vercel, Netlify, or GitHub Pages:

```sh
npm run build
```

Open the resulting HTTPS site in iPhone Safari, tap **Share**, then **Add to Home Screen**. Data are intentionally local to each browser/device in this MVP.
